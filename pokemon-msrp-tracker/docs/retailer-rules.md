# Retailer Rules & Safety Guardrails

## Allowed
- Mock data
- Manual updates
- Official API integrations with compliant usage terms
- Server-side scheduled jobs (when compliant)

## Not Allowed (Current and Default)
- Scraping retailer HTML
- Running retailer fetches on client page load
- CAPTCHA or bot-protection bypassing
- Login-wall bypassing
- Checkout/cart automation
- Circumventing robots/access controls
